# 📌 Problem Statement

Busy parents often struggle to manage healthy meal planning while balancing nutrition, time, budget, and family preferences.

Most meal planning solutions are generic and fail to provide personalized recommendations based on family health data, dietary restrictions, and wellness goals.

NutriNest AI simplifies healthy family living using AI-powered meal generation, nutrition tracking, and grocery planning.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/NutriNest-AI.git
```

---

## 2️⃣ Navigate Into Project

```bash
cd NutriNest-AI
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Create Environment Variables

Create `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_key
VITE_GEMINI_API_KEY=your_gemini_api_key
```

---

## 5️⃣ Run Development Server

```bash
npm run dev
```
